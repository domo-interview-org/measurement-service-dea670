# Measurements

The nurse app records vital signs during a home visit: temperature, pulse and systolic blood
pressure. The app works offline and sends the measurements when the connection returns.

## Requirements

- **REQ-MEAS-1** Only a member of the patient's care team may record a measurement for that
  patient. Anyone else gets `403`.
- **REQ-MEAS-2** A value outside the plausible range is rejected with `400`:

  | Type | Unit | Range |
  |---|---|---|
  | `TEMPERATURE` | °C | 30.0 – 45.0 |
  | `PULSE` | bpm | 20 – 250 |
  | `SYSTOLIC` | mmHg | 50 – 260 |

- **REQ-MEAS-3** Each request carries a `requestId` generated by the app. The app replays a
  request until it receives a `2xx` or a `4xx`. Recording the same `requestId` twice stores one
  measurement and returns it again.
- **REQ-MEAS-4** `measuredAt` is the time on the nurse's device when the measurement was taken,
  sent by the app (ISO-8601 with offset). It can be hours before the request arrives.
- **REQ-MEAS-5** The response contains the measurement's `id`, `type`, `value`, `unit` and
  `measuredAt`.

## API

`POST /patients/{patientId}/measurements`

```json
{
  "requestId": "6f1c2a9e-0d4b-4c1e-9a52-3b8f7e1d2c40",
  "type": "TEMPERATURE",
  "value": 37.2,
  "unit": "°C",
  "measuredAt": "2026-10-20T08:15:00+02:00"
}
```
